# رصد فرص بورصة مسقط (MSX Opportunity Scout)

سكربت يعمل تلقائيًا (يوميًا بعد إغلاق السوق) يجمع بيانات الشركات المدرجة في بورصة مسقط (MSX)، يقارنها ببيانات الأيام السابقة، ويرسل لك تنبيهًا عبر البريد الإلكتروني و/أو تيليجرام عند رصد:

- **حركة سعرية حادة** (ارتفاع/انخفاض ≥ 5% خلال يوم واحد)
- **حجم تداول غير عادي** (أعلى بـ 3 أضعاف من متوسط آخر 5 جلسات)
- **كسر سعري** (سعر إغلاق أعلى/أدنى من آخر 20 جلسة)
- **نتائج مالية فصلية لافتة** (تغير في الأرباح ≥ 30% مقارنة بالفترة السابقة، خلال آخر 3 أيام)

## لوحة المتابعة (Dashboard)

يوفّر المشروع صفحة ويب حية تعرض آخر الفرص المرصودة، وتتيح البحث عن أي شركة لعرض سعرها ومخطط حركتها التاريخي:

**https://salimsrsamri4-tech.github.io/msx-opportunity-scout/**

الصفحة تُحدَّث نفسها تلقائيًا بعد كل تشغيل يومي (تقرأ الملفات في `data/` مباشرة).

## تنبيه مهم

- البيانات تُجلب من نقاط JSON داخلية يستخدمها موقع msx.om نفسه (`companies.aspx/List`, `snapshot.aspx/company`, `Companies-Fin-Pref.aspx/List`)، **وليست واجهة برمجية رسمية معلنة**. قد يتوقف الموقع عن العمل بها أو يغيّرها دون إشعار.
- هذه الأداة **لا تقدّم نصيحة استثمارية**. الإشارات مبنية على قواعد فنية/إحصائية بسيطة فقط، وقرار الشراء أو البيع يبقى مسؤوليتك الكاملة.
- البيانات متأخرة (ليست لحظية) وتُجمع مرة واحدة يوميًا.

## هيكل المشروع

```
src/
  msxApi.js     نقاط الاتصال الأساسية بموقع MSX
  companies.js  جلب قائمة الشركات المدرجة النشطة
  snapshot.js   جلب بيانات السعر/الحجم اليومية لكل شركة
  rules.js      قواعد رصد الفرص (يمكنك تعديل الحدود هنا)
  store.js       حفظ السجل التاريخي في data/history.json
  notify.js      إرسال التنبيهات عبر تيليجرام
  notifyEmail.js إرسال التنبيهات عبر البريد الإلكتروني
  main.js        تشغيل كل الخطوات بالتسلسل
data/history.json   سجل الأسعار التاريخي (يُحدَّث تلقائيًا ويُحفظ في المستودع)
.github/workflows/daily.yml   جدولة التشغيل التلقائي عبر GitHub Actions
```

## خطوات الإعداد

### 1) إعداد قناة التنبيه — البريد الإلكتروني (Gmail)

Gmail لا يسمح باستخدام كلمة مرور حسابك العادية من برنامج خارجي، بل يتطلب "كلمة مرور تطبيق" مخصصة:

1. فعّل **التحقق بخطوتين (2-Step Verification)** في حسابك إن لم يكن مفعّلاً: [myaccount.google.com/security](https://myaccount.google.com/security)
2. اذهب إلى: [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
3. اختر اسمًا (مثلاً "MSX Scout") واضغط **Create/إنشاء**.
4. سيظهر لك رمز من 16 حرفًا (بدون مسافات عند الاستخدام) — هذه هي **كلمة مرور التطبيق**. احتفظ بها؛ لن تُعرض مرة أخرى.

> **مهم:** لا تُدخل هذه الكلمة في أي محادثة أو رسالة معي. أضفها مباشرة كسرّ في GitHub كما في الخطوة التالية.

### 2) رفع المشروع إلى GitHub وضبط الأسرار

المشروع مرفوع بالفعل على: `github.com/salimsrsamri4-tech/msx-opportunity-scout`

من صفحة المستودع: **Settings → Secrets and variables → Actions → New repository secret**، أضف:

| الاسم | القيمة |
|---|---|
| `EMAIL_USER` | عنوان بريدك في Gmail (مثلاً salim.srs.amri4@gmail.com) |
| `EMAIL_PASS` | كلمة مرور التطبيق المكوّنة من 16 حرفًا من الخطوة السابقة |
| `EMAIL_TO` | (اختياري) البريد الذي تريد استقبال التنبيهات عليه، إن كان مختلفًا عن `EMAIL_USER` |

بعد إضافتها، من تبويب **Actions** فعّل الجدولة (تعمل تلقائيًا يوميًا الساعة 14:00 بتوقيت مسقط من الأحد للخميس)، أو شغّلها يدويًا عبر **Run workflow** لتجربتها فورًا.

> قناة تيليجرام لا تزال مدعومة اختياريًا (أضف `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` بنفس الطريقة) إن أصبحت متاحة لديك لاحقًا.

### 3) التشغيل محليًا للتجربة (اختياري)

يتطلب Node.js (الإصدار 18 أو أحدث):

```bash
npm install
EMAIL_USER=... EMAIL_PASS=... node src/main.js
```

بدون ضبط بيانات البريد أو تيليجرام، سيطبع السكربت التقرير في الطرفية فقط دون إرسال.

## تعديل حدود الرصد

كل الحدود (نسبة التغير، معامل ارتفاع الحجم، عدد الأيام...) موجودة في أعلى ملف [`src/rules.js`](src/rules.js) ضمن الكائن `THRESHOLDS`.

## إضافة تحليل بالذكاء الاصطناعي (خطوة مستقبلية)

لتوسيع النظام لاحقًا بحيث يقرأ نصوص الإفصاحات ويحلل أهميتها تلقائيًا عبر Claude API:

1. أنشئ حسابًا على [console.anthropic.com](https://console.anthropic.com) واحصل على مفتاح API.
2. أضفه كسر آخر باسم `ANTHROPIC_API_KEY` في GitHub Secrets.
3. أخبرني عند الرغبة بذلك وسأضيف طبقة التحليل في `src/main.js`.
