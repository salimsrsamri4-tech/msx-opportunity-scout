# رصد فرص بورصة مسقط (MSX Opportunity Scout)

سكربت يعمل تلقائيًا (يوميًا بعد إغلاق السوق) يجمع بيانات الشركات المدرجة في بورصة مسقط (MSX)، يقارنها ببيانات الأيام السابقة، ويرسل لك تنبيهًا عبر تيليجرام عند رصد:

- **حركة سعرية حادة** (ارتفاع/انخفاض ≥ 5% خلال يوم واحد)
- **حجم تداول غير عادي** (أعلى بـ 3 أضعاف من متوسط آخر 5 جلسات)
- **كسر سعري** (سعر إغلاق أعلى/أدنى من آخر 20 جلسة)
- **نتائج مالية فصلية لافتة** (تغير في الأرباح ≥ 30% مقارنة بالفترة السابقة، خلال آخر 3 أيام)

## تنبيه مهم

- البيانات تُجلب من نقاط JSON داخلية يستخدمها موقع msx.om نفسه (`companies.aspx/List`, `snapshot.aspx/company`, `Companies-Fin-Pref.aspx/List`)، **وليست واجهة برمجية رسمية معلنة**. قد يتوقف الموقع عن العمل بها أو يغيّرها دون إشعار.
- هذه الأداة **لا تقدّم نصيحة استثمارية**. الإشارات مبنية على قواعد فنية/إحصائية بسيطة فقط، وقرار الشراء أو البيع يبقى مسؤوليتك الكاملة.
- البيانات متأخرة (ليست لحظية) وتُجمع مرة واحدة يوميًا.

## هيكل المشروع

```
src/
  msxApi.js     نقاط الاتصال الأساسية بموقع MSX
  companies.js  جلب قائمة الشركات المدرجة النشطة
  snapshot.js   جلب بيانات السعر/الحجم اليومية لكل شركة
  rules.js      قواعد رصد الفرص (يمكنك تعديل الحدود هنا)
  store.js      حفظ السجل التاريخي في data/history.json
  notify.js     إرسال التنبيهات عبر تيليجرام
  main.js       تشغيل كل الخطوات بالتسلسل
data/history.json   سجل الأسعار التاريخي (يُحدَّث تلقائيًا ويُحفظ في المستودع)
.github/workflows/daily.yml   جدولة التشغيل التلقائي عبر GitHub Actions
```

## خطوات الإعداد

### 1) إنشاء بوت تيليجرام (لاستقبال التنبيهات)

1. افتح تيليجرام وابحث عن حساب **BotFather**، وابدأ محادثة معه.
2. أرسل له الأمر `/newbot` واتبع التعليمات (اختر اسمًا واسم مستخدم للبوت).
3. سيعطيك **رمز البوت (Bot Token)** بصيغة شبيهة بـ `123456789:ABCdefGhIJKlmNoPQRstuVWXyz`. احتفظ به.
4. ابدأ محادثة مع بوتك الجديد وأرسل له أي رسالة (مثلاً "مرحبا").
5. افتح هذا الرابط في المتصفح بعد استبدال `<TOKEN>` برمز البوت:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
6. ابحث في الرد عن `"chat":{"id":` — الرقم بعدها هو **معرّف المحادثة (Chat ID)** الخاص بك.

### 2) رفع المشروع إلى GitHub وضبط الأسرار

1. أنشئ مستودع جديد على GitHub وارفع هذا المجلد إليه.
2. من إعدادات المستودع: **Settings → Secrets and variables → Actions → New repository secret**، أضف:
   - `TELEGRAM_BOT_TOKEN` = رمز البوت من الخطوة السابقة
   - `TELEGRAM_CHAT_ID` = معرّف المحادثة
3. من تبويب **Actions**، فعّل الجدولة (تعمل تلقائيًا يوميًا الساعة 14:00 بتوقيت مسقط من الأحد للخميس)، أو شغّلها يدويًا عبر **Run workflow**.

### 3) التشغيل محليًا للتجربة (اختياري)

يتطلب Node.js (الإصدار 18 أو أحدث):

```bash
npm install
TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... node src/main.js
```

بدون ضبط المتغيرين أعلاه، سيطبع السكربت التقرير في الطرفية فقط دون إرسال.

## تعديل حدود الرصد

كل الحدود (نسبة التغير، معامل ارتفاع الحجم، عدد الأيام...) موجودة في أعلى ملف [`src/rules.js`](src/rules.js) ضمن الكائن `THRESHOLDS`.

## إضافة تحليل بالذكاء الاصطناعي (خطوة مستقبلية)

لتوسيع النظام لاحقًا بحيث يقرأ نصوص الإفصاحات ويحلل أهميتها تلقائيًا عبر Claude API:

1. أنشئ حسابًا على [console.anthropic.com](https://console.anthropic.com) واحصل على مفتاح API.
2. أضفه كسر آخر باسم `ANTHROPIC_API_KEY` في GitHub Secrets.
3. أخبرني عند الرغبة بذلك وسأضيف طبقة التحليل في `src/main.js`.
